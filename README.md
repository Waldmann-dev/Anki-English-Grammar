# English Flashcards

Flashcard decks from the TXT exports (offline-friendly, no media).

- English Grammar: 2500 exercises in 114 units (14 categories, Units 1–100) + 74 theory Q&A cards.
- English Vocabulary: 1990 words in 6 part-of-speech categories.

Website: open index.html (GitHub Pages) – it loads all cards.tsv live from this repo.
Quiz: Space = show answer, Left = Wrong, Right = Correct.
