# Avanced English 2 – Reverse Deck

2,126 reversed vocabulary cards (front: example sentence with a gap + meaning/synonyms; back: word + full sentence + audio).

The .apkg is 275 MB, too large for a single repo file, so it is split into 8 parts.

1. Download all 8 `.part` files and `join.bat` into one folder.
2. Double-click `join.bat` (Windows) – it merges the parts into `Avanced-English-2-Reverse.apkg`.
   (Manual: `copy /b *.part* Avanced-English-2-Reverse.apkg`)
3. Import the merged file into Anki. It creates the deck tree 'Avanced English 2 - Reverse'; the original deck stays untouched.
