# Avanced English 2 – Reverse Deck

2,126 reversed vocabulary cards (v6: front = meaning without label, then "Synonyms:" line, gap sentence at the bottom; back = the same layout with the gap filled in and the word highlighted in blue, plus the word line and audio).

The .apkg is 275,103,176 bytes (MD5: 4d8adb745766f6266f29b7616d2db3fa), too large for a single repo file, so it is split into 8 parts.

1. Download all 8 `.part` files and `join.bat` into one folder.
2. Double-click `join.bat` (Windows) – it merges the parts into `Avanced-English-2-Reverse.apkg`.
   (Manual: `copy /b *.part* Avanced-English-2-Reverse.apkg`)
3. Check the merged file's MD5 against the value above, then import it into Anki. It updates the existing 'Avanced English 2 - Reverse' cards in place (same note IDs/GUIDs, learning progress is kept); the original deck stays untouched.
